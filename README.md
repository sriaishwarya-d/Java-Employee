Java Employee Payroll

A Java program that calculates employee salary components and displays a detailed pay slip based on the selected designation.

Features
Accepts employee details
Supports multiple designations
Calculates DA, HRA, PF, and Staff Club contributions
Calculates gross salary
Calculates net salary
Displays a detailed employee pay slip
Concepts Used
Classes and Objects
Inheritance
Methods
Constructors
Scanner for user input
Switch-case
Salary calculation
How It Works

The program uses an Employee class to store employee details and calculate salary components. Different employee designations are represented using subclasses such as Programmer, AssistantProfessor, AssociateProfessor, and Professor.

The user enters employee details, selects a designation, and provides the basic pay. The program then calculates the applicable salary components and displays the final pay slip.

Supported Designations
Programmer
Assistant Professor
Associate Professor
Professor
How to Run
Make sure Java is installed on your computer.
Open a terminal in the project folder.
Compile the program:
javac employeeDemo.java
Run the program:
java EmployeeDemo
